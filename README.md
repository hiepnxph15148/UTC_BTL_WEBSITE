# UTC ASM — Frontend Next.js

Project frontend được tạo bằng Next.js (App Router), TypeScript và Tailwind CSS.

## Chạy project

```bash
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000).

## Scripts

| Lệnh | Mô tả |
| --- | --- |
| `npm run dev` | Chạy môi trường phát triển |
| `npm run build` | Build production |
| `npm run start` | Chạy bản production |
| `npm run lint` | Kiểm tra ESLint |

## Cấu trúc chính

- `src/app/page.tsx` — trang chủ
- `src/app/layout.tsx` — layout gốc
- `src/app/globals.css` — style toàn cục (Tailwind)
- `public/` — file tĩnh (ảnh, icon)
